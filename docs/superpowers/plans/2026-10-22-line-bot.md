# Murmur LINE Bot Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 單一 Swift 執行檔 `murmur`：接收 LINE 轉傳的語音，用 macOS 內建語音辨識轉文字、Claude 分析，回覆四則結果。

**Architecture:** SwiftPM 專案，`MurmurCore`（library，所有邏輯，可測）＋ `murmur`（executable，子命令 `serve` / `transcribe` / `analyze`）。外部依賴（LINE、Claude、語音辨識）都藏在 protocol 後面，`Pipeline` actor 串接並負責時間策略。

**Tech Stack:** Swift 6.2、Hummingbird 2（`from: "2.28.0"`）、Speech framework（SpeechAnalyzer / SFSpeechRecognizer）、CryptoKit、URLSession、swift-testing。

**Spec:** `docs/superpowers/specs/2026-10-22-line-bot-design.md`

## Global Constraints

- 平台：`.macOS(.v26)`，arm64；Swift tools 6.2。
- 全部使用者可見文字為繁體中文；逐字稿與 Claude 輸出都經 `Hant.convert`（`StringTransform("Hans-Hant")`）。
- 時間預算：從收到 webhook 起算 **50 秒**內用 reply，否則 push。
- LINE 文字訊息 ≤ 5,000 字（以 `utf16.count` 計，保守），reply/push 一次 ≤ 5 則。
- 設定 key：`LINE_CHANNEL_SECRET`、`LINE_CHANNEL_ACCESS_TOKEN`、`ANTHROPIC_API_KEY`、`ALLOWED_USER_IDS`（逗號分隔）、`CLAUDE_MODEL`（預設 `claude-sonnet-5-5`，實作時以 claude-api skill 確認）、`PORT`（預設 `47821`）。
- `.env` 不進 git；提供 `.env.example`。音檔處理後一律刪除；測試音檔 `~/Downloads/_38494212.m4a` 不複製進 repo。
- 測試指令：`swift test`；單一測試：`swift test --filter <TestName>`。

## Review Focus

1. LINE Console 的「Verify」按鈕送 `{"events":[]}`（簽章有效）→ 必須回 200。測試在 Task 6。
2. 群組／多人聊天室的事件（`source.type` 為 `group`/`room`）→ 一律忽略，只處理 `source.type == "user"`。測試在 Task 5。
3. Claude 回傳某欄為空字串或 `replies` 為空陣列 → 不可送出空白文字訊息（LINE 會回 400），改顯示「（無）」。測試在 Task 3。
4. 含 emoji／罕用字的長逐字稿截斷 → 截斷後 `utf16.count ≤ 5000`，且不切斷 grapheme（不產生破字）。測試在 Task 3。
5. Claude 失敗時回傳的逐字稿 fallback 也很長 → 也要截斷到 ≤ 5,000，總則數 ≤ 5。測試在 Task 5。

### Task 4: LINE API client

**Files:**
- Create: `Sources/MurmurCore/LineClient.swift`、`Tests/MurmurCoreTests/LineClientTests.swift`

**Interfaces:**
- Produces:
  - `public protocol LineAPI: Sendable { func startLoading(userId: String, seconds: Int) async throws; func downloadContent(messageId: String) async throws -> (data: Data, contentType: String?); func reply(token: String, texts: [String]) async throws; func push(to userId: String, texts: [String]) async throws }`
  - `public struct LineClient: LineAPI { public init(accessToken: String, session: URLSession = .shared, pollInterval: Duration = .seconds(1), pollLimit: Duration = .seconds(30)) }`
  - `public enum LineError: Error, Equatable { case notFound, gone, transcodingFailed, transcodingTimeout, http(Int) }`

- [ ] **Step 1: 寫失敗測試**（`URLProtocol` stub，`pollInterval` 設極小）
  - download 200 → 回傳 data 與 `Content-Type`；URL 為 `https://api-data.line.me/v2/bot/message/M1/content`，header `Authorization: Bearer <token>`
  - 首次 202 → 輪詢 `.../content/transcoding` 回 `processing` 再 `succeeded` → 再下載成功
  - transcoding `failed` → `.transcodingFailed`；一直 `processing` 超過 `pollLimit` → `.transcodingTimeout`
  - 404 → `.notFound`；410 → `.gone`
  - reply：`POST https://api.line.me/v2/bot/message/reply`，body `{"replyToken":..,"messages":[{"type":"text","text":..}]}`；push：`POST .../message/push`，body `{"to":..,"messages":[..]}`；loading：`POST https://api.line.me/v2/bot/chat/loading/start`，body `{"chatId":..,"loadingSeconds":60}`

固定文案：
- 非語音：`請轉傳語音訊息給我，我會幫你整理逐字稿、重點、情緒與回覆建議。`

- 辨識空白：`沒有辨識到語音內容。`
- 其他錯誤：`處理失敗，請稍後再試。`
